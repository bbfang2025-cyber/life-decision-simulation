# 提问总库（按六格分类 · 48 问）

> 用法：**不要按顺序念。** 先用 SKILL.md 第 5.2 节做六格体检，看哪格是空的，再来这里挑那一格的问题。每一问都是四件套：**怎么问 / 撬动哪一步 / 什么答案会翻转结论 / 什么时候别问**。
>
> 第三列才是关键。**如果两种答案都指向同一个结论，这个问题就不该问。**

---

## 第一格 · 选项（桌上到底摆了哪几个）

对应：**第一步 · 拆解（马斯克 · 第一性原理）**。缺这格，会以为自己只有两条路。

| 问法（挑最贴的一句说） | 撬动 | 什么答案会翻转结论 | 什么时候别问 |
|---|---|---|---|
| 除了 A 和 B，还有第三种吗？哪怕听起来很傻的那种 | 拆解 | 能说出第三种 → 整个决策从"选"变成"设计"，四步要重排 | 用户已经列了三个以上选项 |
| 你说的这个机会，对方给你了吗？还是你自己觉得有？ | 拆解 | 还没给 → 现在不是决策，是等待，讨论"去不去"毫无意义 | 已有书面 offer |
| 如果这两个都不能选，你会再造一个什么出来？ | 拆解 | 造得出 → 说明真正的约束不是选项，是想象力 | 用户明显已经被现实锁死（如重病、照顾失能老人） |
| 这件事是"必须现在选"，还是"你现在想选"？ | 时点 | 是"想选" → 时间压力是假的，可以慢慢验证，不必赌 | 有硬截止日期（offer 到期、房子过户） |
| 你有没有把"不选"当成一个选项算过？ | 取舍 | 没算过 → 很可能"不选"才是最优解，尤其当两个选项都很差时 | 不选就等于默认失去（如错过落户年龄） |
| 这件事里，多少是你在选，多少是别人在替你选？ | 内心 | 大部分是别人 → 这不是你的决定，先解决"谁在替你做主" | 用户明确说"这是我自己定的" |
| 如果只能留一个，另一个永远不能再碰，你留哪个？ | 取舍 | 答得干脆 → 取舍那步直接过；答不出来 → 他其实两个都不想要 | 还没把选项列全 |
| 这个选项是你找来的，还是找上你的？ | 拆解 | 找上你的 → 你在回应别人，不是在规划自己 | 明显是主动求职/主动创业 |

## 第二格 · 时点（为什么是现在）

对应：**第一步 · 拆解（马斯克 · 第一性原理）**。缺这格，分不清是机会在敲门还是你在逃。

| 问法 | 撬动 | 什么答案会翻转结论 | 什么时候别问 |
|---|---|---|---|
| 为什么是现在？三个月前为什么没动？ | 拆解 | 三个月前就想了但没动 → 真正卡住他的不是这件事，是别的东西 | 事情刚发生（如昨天被裁） |
| 什么事件让你这周开始想这件事？ | 拆解 | 是一次冲突、一句评价、一场病 → 触发事件往往才是真问题 | 用户已说明触发事件 |
| 再等三个月再定，会失去什么？ | 拆解 | 什么都失去不了 → 不许现在做不可逆决定，先验证 | 有硬窗口（年龄、岗位、对方等不了） |
| 这件事你纠结多久了？ | 内心 | 超过半年 → 纠结本身已经是答案：他不想选，他在拖 | 刚发生 |
| 如果明天必须给答复，你会怎么答？ | 内心 | 答得飞快 → 他早有答案，来找许可的（配合第 5 步照妖镜用） | 用户情绪不稳时 |
| 有没有一个截止日期在逼你？这个日期是谁定的？ | 拆解 | 日期是他自己编的 → 压力是自造的，可以拆掉 | 日期是对方/制度定的 |
| 如果这件事可以拖到明年，你还会现在做吗？ | 取舍 | 不会 → 那你要的不是这件事，是逃离现在的状态 | 有不可延期因素 |

## 第三格 · 数字（代价的准数）

对应：**第三步 · 长期（芒格 · 逆向思维）**。缺这格，所有"值不值"都是感觉。

> ⚠️ **这一格最容易骗人。** "收入减半"是最典型的陷阱：北京 2.8 万、房租 6000；老家 1.2 万、有房。账面砍一半，**净现金流几乎一样**。所以永远不要接受比例，只要绝对数。

| 问法 | 撬动 | 什么答案会翻转结论 | 什么时候别问 |
|---|---|---|---|
| 收入从多少到多少？给我两个绝对数，别说比例 | 长期 | 算完净现金流是正的 → 第三步大半已过，"减半"是假恐惧 | 用户已经给了两个绝对数 |
| 两边每个月的固定支出分别是多少？ | 长期 | 支出降得比收入多 → 这个决定在经济上是升级不是降级 | 已知支出结构 |
| 可动用的钱（不算房子、不算父母的钱）够撑几个月？ | 长期 | 撑不到三个月 → **一票否决**，从"要不要"改成"先攒跑道" | 用户明确不担心钱 |
| 最坏那个月，你要支出多少？缺口多少？ | 长期 | 缺口需要借钱/断供 → 触发大亏线，收益再高也不做 | 已有稳定被动收入覆盖 |
| 不做这件事，你本来能拿到什么？（机会成本） | 取舍 | 机会成本比收益高 → 这个选择本身就不成立 | 手上没有别的机会 |
| 最便宜的验证方式要花多少钱？ | 拆解 | 只要几百块 → 立刻去验，别做决定 | 已验证过 |
| 三年后两边的年收入大概多少？ | 长期 | 交叉点在两年内 → 短期亏是投资的，不是亏损 | 收入结构不可预测（创业早期） |
| 有没有一笔钱是"动了就回不来"的？ | 长期 | 有 → 这笔钱不许动，这是硬约束 | 无大额支出 |

## 第四格 · 人（谁被卷进来）

对应：**第二步 · 取舍 + 第三步 · 长期**。缺这格，会用一个人的算法处理两个人的事。

| 问法 | 撬动 | 什么答案会翻转结论 | 什么时候别问 |
|---|---|---|---|
| 这件事还有谁要被卷进来？ | 取舍 | 有孩子/老人/合伙人 → 决策主体从"我"变"我们"，四步要重排 | 用户独居且无牵绊 |
| 他/她知道吗？态度是什么？ | 取舍 | 完全没沟通过 → **这已经不是决策问题，是知情问题**，先解决这个 | 已知对方态度 |
| 如果他不支持，你还做吗？ | 内心 | 犹豫 → 他在拿关系赌一个不确定的收益，风险被低估了 | 对方明确支持 |
| 他/她自己还有什么选项？为了你，他放弃了什么？ | 取舍 | 对方也放弃了东西 → 这笔账要算进来，否则是隐性负债 | 对方是未成年人/无自主能力 |
| 家里的刚性支出谁在承担？断了谁先受影响？ | 长期 | 有不能断的支出（药费、学费）→ "最坏情况"不是亏钱，是断供 | 无刚性支出 |
| 父母身体怎么样？有没有可能需要你随时回去？ | 长期 | 有大病风险 → 距离变成一个硬约束，不只是情感问题 | 父母健康且有兄弟姐妹分担 |
| 孩子多大？上学怎么安排？ | 长期 | 涉及学区/转学 → 这不是一年的决定，是六年的 | 无子女 |
| 谁在劝你做？谁在劝你别做？劝你的人自己做成过吗？ | 内心 | 劝的人自己没做成 → 他的意见是情绪不是经验，可以降权 | 无人干涉 |

## 第五格 · 底线（什么绝对不能失去）

对应：**第三步 · 长期（芒格 · 逆向思维）**。缺这格，谈长期是空话，还可能把人推下悬崖。

| 问法 | 撬动 | 什么答案会翻转结论 | 什么时候别问 |
|---|---|---|---|
| 什么绝对不能失去？列三个 | 长期 | 列出的东西会被这个决定直接威胁 → 触发一票否决 | 用户说"没什么不能失去的"（这句本身要追问） |
| 哪条线一破，你就必须回头？ | 长期 | 说不出 → 他没有退路设计，这是最危险的状态 | 已明确止损线 |
| 你能接受的最差状态，具体是什么样？ | 长期 | 描述得出具体画面 → 说明他想过；说"没想过" → 他在靠运气 | 用户已描述过 |
| 撑多久不崩？这个时间够不够你翻身？ | 长期 | 撑的时间 < 翻身所需 → 时间不够，方案不成立 | 有稳定现金流 |
| 如果亏掉一半本金，你还起得来吗？ | 长期 | 起不来 → 这笔钱不许投，无论收益多高 | 无本金投入 |
| 健康、信用、关键关系，哪一项可能被一把输光？ | 长期 | 任意一项 → 大亏线触发，优先级高于一切收益 | 三项都有冗余 |
| 如果所有人都反对，你一个人扛得住几个月？ | 内心 | 扛不住一个月 → 这个决定需要盟友，不是需要勇气 | 已有支持系统 |
| 你有什么是"输不起"的？（他通常会笑，然后说出真话） | 内心 | 说出来的东西和这个决定直接冲突 → 这是全场最重要的发现 | 情绪不稳时 |

## 第六格 · 证据（验证过什么）

对应：**第一步 · 拆解 + 第四步 · 内心**。缺这格，该做实验不该做决定。

| 问法 | 撬动 | 什么答案会翻转结论 | 什么时候别问 |
|---|---|---|---|
| 为这件事你做过什么？聊过谁、试过什么、花过钱吗？ | 拆解 | 一件都没有 → **现在不该决策，该去做实验**，总判强制降级 | 已验证过多轮 |
| 谁真做成了？他条件跟你差多少？ | 拆解 | 做成的都比他条件好一大截 → 这不是"没人干过"，是"你这条件干不了" | 行业里确实没人做成 |
| 你身边有谁做失败了？他怎么失败的？ | 长期 | 失败原因正是他的短板 → 这是最便宜的预警，必须写进报告 | 无失败案例可查 |
| 你说"我能行"，有什么证据？ | 内心 | 举不出具体事例 → 这是愿望不是判断，标【待验证】 | 有明确履历支撑 |
| 这件事里，哪个部分是你亲眼看过的，哪个是听说的？ | 拆解 | 关键假设全靠听说 → 这个决定建立在传言上 | 有第一手经验 |
| 如果让你两周内验证最关键的一个假设，你会怎么验？ | 拆解 | 说得出 → 拆解那步基本过；说不出 → 他还不知道自己在赌什么 | 已验证完毕 |
| 你有没有在别的事上证明过自己能做类似的事？ | 内心 | 有跨领域成功经验 → 迁移能力被低估，可以加分 | 无相关经历 |
| 你现在最确信的那件事，是怎么确信的？ | 内心 | 答案是"大家都这么说" → 他的确信是借来的 | 有亲历证据 |

## 附：五类常见决策的开局三问

不同类型的决定，六格里最先空的那格不一样。**先用这三问开局，再按体检结果补。**

### 换城市 / 回老家 / 异地

1. **对方（伴侣/家人）现在在哪座城市？** → 翻转级。人在北京＝你造出异地；人在老家＝你结束异地；人在第三城＝回不回都是异地。
2. **目的地的工作定了吗，还是回去再找？** → 翻转级。有 offer 和没 offer 是两个完全不同的决定。
3. **两边各减到多少、各花多少？净现金流差多少？** → 否决级。"减半"常常是假恐惧。

### 跳槽 / 转行

1. **这个机会是找上你的，还是你找的？** → 判断主动还是被动。
2. **你讨厌的是这份工作，还是这个行业？** → 拆解那步的核心一刀。换公司解决不了行业问题。
3. **新工作的收入、稳定性、成长，哪一项是变差的？** → 只要有一样变差且不可接受，取舍那步就开始了。

### 裸辞 / 创业

1. **手上能撑几个月？** → 否决级，撑不到六个月不谈创业。
2. **有人为这个东西付过钱吗？一分也算。** → 证据格。没有＝还没验证，不叫创业，叫想法。
3. **最坏情况你会亏掉什么？亏完还起得来吗？** → 大亏线。

### 关系（结婚 / 分开 / 异地）

1. **对方知道你在纠结这件事吗？** → 不知情＝这不是决策问题，是沟通问题。
2. **除了"在一起"和"分开"，你想过第三种吗？** → 拆解那步。多数人卡在二选一。
3. **如果三年后维持现状，你会怎么评价今天？** → 内心那步。答"会后悔"＝这一步过。

### 买房 / 大额支出

1. **月供占家庭月收入多少？超过 50% 吗？** → 否决级。
2. **断供会发生什么？最坏能坏到哪？** → 大亏线。
3. **这笔首付动了，还回得来吗？** → 可逆性。不可逆的，风险权重整体上调。

## 附：提问的三个反例（照着念会翻车）

**❌ 反例 1：把六个问题攒成一段**
> "你想清楚了吗？钱够吗？家里同意吗？最坏情况是什么？有没有别的选择？打算什么时候定？"
>
> 结果：用户只回答最好答的那个，剩下的全部跳过。你浪费了五次机会。

**❌ 反例 2：问感受不问事实**
> "你现在压力大吗？""你对这个决定焦虑吗？"
>
> 结果：得到"还行吧""有点"。零信息。改成"最坏那个月你要还多少钱"，才有信息。

**❌ 反例 3：问他已经答过的**
> 用户上一句说"收入减半"，你下一句问"那收入会变吗？"
>
> 结果：他立刻知道你只是在走流程，不是在听。信任一次性掉光。
